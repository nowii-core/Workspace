Una piattaforma enterprise di AI Operations costruita con **HTML, CSS e JavaScript puri**. Nessuna dipendenza esterna, nessun backend.

## ✨ Funzionalità

- **Dashboard multi-tenant** con workspace switcher
- **KPI live** con count-up animato e sparkline dinamiche
- **Grafico canvas** revenue vs traffic (interattivo per timeframe)
- **Mappa mondiale** con nodi data center e connessioni animate in tempo reale
- **Operations center** con tabella eventi filtrabile, sort e bulk select
- **CRM clienti** con health score, sentiment e dettaglio 360°
- **AI Copilot** con 7 pattern di risposta e streaming lettera per lettera
- **Copilot drawer** laterale sempre accessibile
- **Command Palette** (⌘K) con 20+ comandi e azioni rapide
- **Quick Search** inline (`/`) su eventi, clienti e team
- **Reports** generabili con export CSV
- **Team management** con presence live
- **Notifiche** con badge e centro notifiche
- **Creazione incidenti / clienti / inviti** tramite modal
- **Export CSV** e **export JSON** completo
- **Auto-refresh** configurabile ogni 30 secondi
- **Tema chiaro/scuro** con densità personalizzabile
- **Effetti magnetici** attivabili dalle impostazioni
- **Onboarding tour** alla prima apertura
- **Salvataggio automatico** su localStorage
- **Scorciatoie tastiera** complete

## 🛠 Tecnologie

- HTML5
- CSS3 (Grid, Flexbox, animazioni, backdrop-filter, custom properties)
- JavaScript (ES6+, Canvas 2D API, localStorage, MutationObserver, Event Delegation)

## 📖 Scorciatoie

| Tasto | Azione |
|---|---|
| `⌘ K` / `Ctrl K` | Apri command palette |
| `⌘ J` / `Ctrl J` | Apri AI Copilot drawer |
| `/` | Focus quick search |
| `R` | Aggiorna dati |
| `1` - `6` | Naviga tra le viste |
| `ESC` | Chiudi modal / drawer |

## 🚀 Deploy

Basta aprire `index.html` nel browser. Per GitHub Pages:

1. Settings → Pages
2. Branch: `main`, cartella `/` (root)
3. Salva

Demo live: `https://nowii-core.github.io/nowii-ai/`
